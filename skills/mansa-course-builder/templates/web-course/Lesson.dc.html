The Workflow schema

Once the tree exists, a single feature or fix moves through a repeatable pipeline instead of an unstructured chat session.

Five phases, one direction

Init
Plan
Validate
Implement
Ship
Scaffold the reference file, pick the task type
Design the approach — files, risks
Caution gate — check the plan against existing code first
Write the code, run it, fix it
Done — commit, push, record the rollback point
one orchestrating skill drives all five
The phases exist so nothing gets skipped under time pressure.
Validate is the phase that catches "wait, this table already exists" before code gets written, not after. It is the only caution gate in an otherwise straight line.
Try it · 10 min

Narrate one real change, phase by phase

Pick a small fix you did recently. Write one line for what happened in each phase — and be honest about the ones you skipped.
