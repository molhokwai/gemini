The three AI schemas

Where things live, how a change moves through the system, and how the system improves itself. Every AI tool setup that scales past one prompt in a chat window needs all three.

What you will be able to do

TREE
Separate a project's behavior, decisions and code into three places
.claude/skills, pm/tasks and src — and know why each changes at a different speed.
WORKFLOW
Move one change through Init → Plan → Validate → Implement → Ship
Instead of an unstructured chat session — so nothing gets skipped under time pressure.
CYCLE
Keep your AI skills in sync with the real codebase
Doing, detecting, updating — the loop that stops "the AI knows how we work" going stale.
