# Skill: Psychology Study Integration System
<!-- Name: /psychology-study -->
<!-- Description: Formalizes real-world behavioral observations into structured academic logs, tracks course progression, maps lessons, and audits CLEP/PLAR degree readiness. -->

## CLI Sub-Command Routing Rules
- If command includes `check-structure`, run **Module 5: Workspace Integrity Audit**.
- If command includes an explicit progress update (e.g., "mark Yale as Started"), run **Module 3: Progress Tracking Module** to rewrite the status fields inside `PROGRESS.md`.
- Default behavior for all other inputs runs **Modules 1, 2, 3, and 4** sequentially.

---

## 1. Clinical & Academic Analysis Module
### Objective
Deconstruct intuitive descriptions of behavior (concerning family, friends, or strangers) into formal, validated psychological definitions.
### Execution Instructions
- Identify the raw behavior or pattern described by the user.
- Explicitly connect it to official academic frameworks (e.g., Attachment Styles, Cognitive Biases, Big Five Personality Traits, Defense Mechanisms, or Heuristics).
- Provide a rigorous, academic explanation of *why* the behavior fits this mechanism, moving beyond casual intuition.

## 2. Curriculum Mapping Module
### Objective
Directly cross-reference the current observation back to the formal Yale (PSYC 110) or MIT (9.00SC) curriculum requirements.
### Execution Instructions
- Search `PROGRESS.md` to find the exact lecture or reading assignment where this mechanism is taught.
- Output a precise recommendations table using the exact following format:

| Curricular Source | Target Module / Lecture | Required Reading / Study Items | Validation Test Item |
| :--- | :--- | :--- | :--- |
| [e.g., Yale PSYC 110] | [e.g., Lecture 9: Clinical / Social] | [e.g., Read Nettle Ch. 2; Review Attachment theory logs] | [e.g., Take Yale Midterm Section B] |

## 3. Progress Tracking Module
### Objective
Dynamically manage the state machine of the user's ongoing coursework by parsing and modifying `PROGRESS.md`.
### Execution Instructions
- Read the current progress from the `PROGRESS.md` tree.
- When explicitly requested, toggle the tracking checkboxes (`[ ]` to `[x]`) and match the lifecycle keywords exactly:
  - `[ ] Planned`
  - `[ ] Started`
  - `[ ] Ongoing`
  - `[ ] Mastered & Documented` (Lectures and readings logged)
  - `[ ] Validated Competency` (Exam completed, graded, and archived)
- Output the current updated state of the active module.

## 4. Degree & Certification Readiness Audit (CLEP / PLAR)
### Objective
Evaluate how close the user's documented, verified material is to earning official university recognition or testing out of requirements.
### Execution Instructions
- **CLEP (Introductory Psychology Exam) Audit:** Track progress toward matching the 100-question American Council on Education (ACE) layout. Verify if the user has demonstrated competency in the required proportions: Biological (20%), Cognitive (15%), Developmental (15%), Social (10%), Clinical (15%). Output an exact percentage of CLEP coverage.
- **PLAR (Prior Learning Assessment Portfolio) Audit:** Inspect the active directory to ensure the `Conceptual_Logs/` match the exact syllabi and that `Exams_and_Validation/` holds the graded exam sheets.
- Provide a direct list of explicit missing documentation items needed to pass a formal university assessment.

## 5. Workspace Integrity Audit Module
### Trigger Command
- `/psychology-study check-structure`
### Objective
Verify that the required tracking folder hierarchies exist on the local file system.
### Execution Instructions
- Scan the execution path for the presence of:
  - `Psychology_Portfolio/01_Introduction_to_Psychology/Conceptual_Logs/`
  - `Psychology_Portfolio/01_Introduction_to_Psychology/Exams_and_Validation/`
- If folders are missing, output an alert message and direct the user to run the Python generation script.
- If directories exist, return: `🟢 Workspace Integrity: Verified. Folders match required academic specifications.`

## Standardized CLI Output Format
Every response generated by the `/psychology-study` default action must use these exact scannable headers:

### 🧠 Psychological Formulation & Commentary
*(The formal translation of the intuitive observation)*

### 🗺️ Curricular Mapping & Assignments
*(The tracking table mapping out what to study or test next)*

### 📈 Current Academic Progression State
*(The structural status tracking update from PROGRESS.md)*

### 🎓 CLEP & PLAR Readiness Portfolio Audit
*(The clear indicator of steps remaining before moving to a degree program)*


## Response Format & Length Constraint (User Rule)
- **Max Length:** Maximum 20 lines per response.
- **Required Links:**
  - `[Read this]` links pointing to course elements to read.
  - `[Expand to file]` links for details to write to a file if any.
  - `[Exercise / Questions / Exams]` links pointing to exercises, questions, or exams to pass to validate elements.
